# groupA_Bed_Management
Predicting a patient’s length of stay:

With varying demand but a fixed capacity of beds, bed managers at 
WWL have the difficult job of making critical decisions in facilitating 
the effective use of acute hospital beds, often relying on their own 
experience, initiative, supplementary data, and forecasts during this 
process.  

Task: 
 
• Explore the dataset and summarise it.  
• Build and evaluate a model which predicts patient length of 
stay in days or hours. 
• Suggest additional data which could be used to improve your 
model.  
• Using these results as context, describe the importance of 
selecting an appropriate date range for building a model.
